# 🎬 Reelogue

Кинодневник в стиле Letterboxd: каталог фильмов и сериалов через TMDB,
оценки по 10-балльной шкале, рецензии, комментарии, кинодневник, любимые
фильмы, кастомные списки, подписки и лента активности. Авторизация — через
Telegram-бота с регистрацией прямо в чате.

## Стек
- **Backend:** Node.js + Express
- **Bot:** grammY (один файл `bot.js`)
- **БД:** SQLite через `better-sqlite3` (без ORM)
- **Frontend:** чистый HTML / CSS / JS (папка `site/`)

## Запуск

```bash
npm install                 # ставит зависимости (better-sqlite3 соберётся/скачается сам)
cp .env.example .env        # заполните переменные
node server.js              # сайт + API   →  http://localhost:3000
node bot.js                 # Telegram-бот (в отдельном терминале)
# либо разом:  npm run dev
```

### .env
| Переменная        | Обязательна | Описание |
|-------------------|:-----------:|----------|
| `SITE_URL`        | да          | Публичный адрес сайта без слэша в конце (для callback-ссылок) |
| `BOT_TOKEN`       | да          | Токен бота от [@BotFather](https://t.me/BotFather) |
| `TMDB_API_KEY`    | да          | Ключ TMDB v3 — themoviedb.org/settings/api |
| `PORT`            | нет         | Порт сервера (по умолчанию 3000) |
| `KINOPOISK_API_KEY` | нет       | Ключ kinopoisk.dev — включает точные ссылки «Смотреть» (см. ниже) |

> Бот и сервер используют одну общую базу `reelogue.db`, поэтому держите их в одной папке.

## Как работает вход
1. На сайте — кнопка **«Войти через Telegram»**. Сайт создаёт одноразовый токен
   и открывает `t.me/<bot>?start=auth_<токен>`.
2. Бот узнаёт пользователя или регистрирует нового **прямо в чате**
   (имя пользователя → отображаемое имя, аватар берётся из Telegram).
3. Бот присылает кнопку-ссылку `SITE_URL/auth/callback?token=<токен>` —
   она действует **10 минут**. Клик авторизует в браузере.
4. Исходная вкладка тоже опрашивает статус, так что вход подхватывается
   автоматически. Использованные и просроченные токены удаляются.

## Кнопка «Смотреть» и Kinopoisk ID
Задача — открыть `https://www.sspoisk.ru/film/<KINOPOISK_ID>/`. Загвоздка в том,
что **TMDB не отдаёт Kinopoisk ID** (только IMDb ID). Поэтому:

- Если задан `KINOPOISK_API_KEY` (бесплатный, от [@kinopoiskdev_bot](https://t.me/kinopoiskdev_bot)),
  сервер резолвит цепочку **TMDB → IMDb → Kinopoisk ID** и ведёт прямо на
  `sspoisk.ru/film/<id>/` — ровно в нужном формате.
- Если ключа нет — кнопка ведёт на **поиск по названию** на sspoisk.

Логика — в роуте `GET /watch/:type/:id` в `server.js`, менять легко.

## Проверки
- Все JS-файлы проходят `node --check`.
- Полная SQL-схема и все запросы протестированы на движке SQLite
  (case-insensitive логин, claim токена, `ON CONFLICT`-upsert статусов и
  избранного, лента подписок, агрегаты статистики, очистка токенов,
  каскадное удаление).
